## Class unification

- Unified order: `0 = fire`, `1 = smoke`.
- D-Fire ships `0 = smoke, 1 = fire` → **remapped** (verified with contact sheets).
- FASDD ships `0 = fire, 1 = smoke` → unchanged.
- Local seed verified with `scripts/contact_sheet.py`.

## Deduplication / leakage control

`scripts/prepare_data.py` computes a 64-bit perceptual hash for every image:

- exact/near duplicates (Hamming ≤ 2) are collapsed;
- near-identical frames (Hamming ≤ 6) are grouped into a **scene**;
- a TEST scene that also appears in train/val is **dropped from TEST**;
- a val scene that appears in train is moved to train.

Input 117,325 → kept 75,637 (39,393 exact-duplicate drops, 2,295 test drops,
1,389 val→train moves). The frozen TEST file is locked in
`data/splits/TEST.lock.json` (sha256 `aba7961e910edb50fe1e0be0406ab596cc3a7ed4e204b0fe500b17304ab9d9aa`,
0 scene overlap with train/val).

## Hard negatives

`data/negatives/mined/` and `data/negatives/mined_lowconf/` contain false-positive
crops mined **only from TRAIN non-fire images and non-fire video**. TEST images
are never used for mining. `data/clips/clips.jsonl` defines the fire/smoke and
non-fire video clips with verified onset times.
